How Document Verification Works

We combine deterministic scoring with AI-based reasoning to verify document authenticity.

1

Deterministic Hashing

Each file or ID is converted into a numeric hash, ensuring the same doc always gets the same score.

2

Trust Score

Based on the hash and QR status, we generate a trust score (80–95 or 1–40).

3

OpenRouter AI

Optionally, an AI model explains the verification result using the OpenRouter GPT API.
